Health Checks

Verify every component in your Ash Linux stack is running correctly.

Component Health

Qdrant

Vector database on :6333

curl -s http://localhost:6333/health
→ {ok:true}

Ollama

Embedding model on :11434

curl -s http://localhost:11434/api/tags
→ Must contain nomic-embed-text

LSFS Daemon

File indexer (user service)

systemctl --user status lsfs-daemon
→ Active: active (running)

Launcher Hook

Super+Space script

test -x ~/.config/scripts/lsfs_launcher_hook.sh
→ Exit code 0

End-to-End Test

Verify the full pipeline works together:

  # 1. Query via CLI
  lsfs-query 'my config files'

  # 2. Check Qdrant collection
  curl -s http://localhost:6333/collections | python3 -m json.tool

  # 3. Live daemon logs
  journalctl --user -u lsfs-daemon -f

Auto-Fix

If any check fails, re-run the installer — it's fully idempotent:

  curl -sfL https://raw.githubusercontent.com/exonew2/files/main/scripts/ash-install.sh | sudo bash
