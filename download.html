Prerequisites

  • Arch Linux — any installation (bare metal, VM, WSL2, container)
  • Root/sudo access — for systemd services and package installation
  • Internet connection — for initial package download and model pull (offline after setup)
  • 4 GB RAM minimum — 8 GB recommended for desktop use

What the Installer Does

Phase 1 — Packages

Installs dependencies: Python, curl, wofi, jq, fd, kitty, and build tools.

Phase 2 — Qdrant

Downloads standalone binary. Creates system user, data directory, and systemd service on port :6333.

Phase 3 — Ollama

Installs Ollama, enables systemd service, pulls nomic-embed-text model.

Phase 4 — LSFS Daemon

Deploys Python indexer + bash launcher + query CLI. Systemd user service with polling watcher.

Phase 5 — Launcher

Binds Super+Space to semantic search in Hyprland. Wofi-based results menu.

Phase 6 — Verification

Health checks all 4 components. Prints dashboard with status and next steps.

After Installation

  1. Press Super+Space to open the semantic search launcher.
  2. Type a query — "my notes", "config files", "files from last 2h".
  3. Select a result to open it in Kitty + Neovim (files) or Yazi (directories).
  4. Use lsfs-query 'your query' for CLI search without the GUI.

Troubleshooting

Qdrant not running?
sudo systemctl status qdrant — check logs with sudo journalctl -u qdrant -n 50.
Ollama unreachable?
systemctl status ollama — restart with sudo systemctl restart ollama.
Launcher not appearing?
Ensure Hyprland is running. Check ~/.config/hypr/hyprland.conf for the Super+Space bind.
LSFS daemon not running?
systemctl --user status lsfs-daemon — logs with journalctl --user -u lsfs-daemon -f.

Re-run the installer — it is idempotent and safe to run multiple times.
