[ search ]

# semantic file search. vector database. local embedding model. press super+space.

$ cat semantic-search
Semantic File Search
Search files by meaning, not just filename. "database config files" finds postgresql.conf, prisma/schema.prisma, and docker-compose.yml — because they share semantic context, not a keyword.
$ cat vector-db
Qdrant Vector Database
Every file is embedded as a 768-dimensional vector. Qdrant stores and searches them with cosine similarity. Dedicated service, port 6333.
$ cat local-ai
Ollama + nomic-embed-text
Local embedding model (nomic-embed-text, 768-dim). No cloud calls, no API key, no data leaving your machine. GPU-accelerated when available.
$ cat desktop
Desktop Integration
Hyprland, Waybar, Kitty terminal, Wofi launcher. Super+Space opens a search bar that understands what you mean. Results open in your editor.
$ cat safety
Rollback & Safety
Btrfs snapshot before installation. Idempotent installer — re-run anytime, never breaks. Every modified config file is backed up to /var/backups.
$ cat setup
Single Command Setup
Interactive TUI installer with dry-run mode, configurable profiles (desktop/server/ ci/minimal), and checksum-verified downloads. Works on x86_64 and ARM64.

[ commands ]

# everyday usage. search by meaning, by time, by type. all from the terminal.

$ lsfs-query 'database config files'
Semantic search — finds files by meaning, not keywords. Returns paths scored by cosine similarity.
$ lsfs-query 'files from last 3 days'
Time-based fallback — when the semantic model can't parse a time query, fd takes over.
$ Super+Space → search → open
Desktop launcher — type any query, see results sorted by relevance, press enter to open in Kitty + Neovim.
$ ash-doctor
Health check — verifies all services, ports, permissions, disk space, and GPU status. 40+ checks.
$ journalctl --user -u lsfs-daemon -f
Watch the daemon live — see files being indexed in real time, filtered by user service.
$ curl ... | sudo bash
Re-run anytime — the installer is idempotent. Detects existing state and resumes. Never duplicates.
