Ash Linux

A highly interactive TUI installer that runs over an existing Arch Linux system, transforming it into the ultimate AI-native "Vibe Machine". Semantic search, local LLM routing, and Btrfs snapshots out of the box.

// Run this as your regular user on Arch Linux:
curl -sfL https://raw.githubusercontent.com/exonew2/files/main/scripts/ash-install.sh | sudo bash

Detailed Feature Specifications

Ash Linux is composed of over a dozen integrated daemons and services. Below is the complete feature matrix.

1. Semantic File Search (LSFS)

  • Vector-embedding search: Powered by Ollama (`nomic-embed-text`) and Qdrant database.
  • FUSE Filesystem: Virtual browsable directories mounted at `/mnt/lsfs` (e.g., `by-name/`, `by-content/`, `by-tag/`, `recent/`).
  • Query Filters: Supports `ext:`, `type:`, `name:`, `before:`, `after:`.
  • Cross-encoder reranking: Uses `ms-marco-MiniLM-L-6-v2` for hyper-accurate relevance sorting.
  • Index Control: Respects `.lsfsignore` for privacy and scope management.

2. Built-in Terminal Interfaces (TUIs)

  • ash-tui: Python Textual dashboard (Tabs: AI Stack, Logs, Packages, SystemMonitor, AIStackPanel, LogViewer).
  • Installer TUI: `whiptail/dialog` based setup with rollback menus, retry/abort logic, and shell escapes.
  • Model Selector: GTK4/libadwaita graphical model manager (pull/remove Ollama models dynamically).

3. AI Desktop Environment & Launchers

  • Wofi Integration: `Super+Space` for semantic file search (ranked results with file-type emojis).
  • AI Intent Launcher: `Super+Shift+Space` powered by usage-pattern tracking and LLM intent resolution.
  • Desktop Stack: Hyprland (Wayland), Kitty, Wofi, Waybar, Swaync, Starship, Zsh/Fish.
  • Waybar Widgets: Live Ollama model status, Qdrant collection count, and LSFS mount status.

4. AI Services & Routing

  • Ollama & Qdrant: Core inference and vector memory running natively.
  • ash-model-router.py: Dynamic task routing (autocomplete → `qwen2.5-coder:1.5b`, code gen → `deepseek-coder:6.7b`, reasoning → `qwen2.5:32b`).
  • NotebookLM Sync Daemon: Pushes context via MCP stdio directly into Qdrant.
  • D-Bus Daemons: Ash Agent (health monitor/AI suggestions) and Ash Workspace Manager (layout suggestions).

5. MCP & Agent Integrations

  • Global MCP Exposure: Servers auto-configured for Claude Desktop, Cursor, Windsurf, Cline, OpenCode, and Gemini.
  • 3 Native Servers: `notebooklm`, `ash-project` (indexes over 4,500 files), and `codebase-memory`.

6. Security & Sandboxing

  • Dependency Firewall: Wraps `npm`, `pip`, and `cargo` to prevent AI slopsquatting using Levenshtein distance detection.
  • Btrfs CoW Snapshots: Take instant revertable snapshots before agent execution via `ash sandbox start/rollback`.
  • Hardening: Systemd isolation, nftables firewall, AppArmor, SSH hardening, and kernel sysctl tuning.
  • Audit Logging: Full supply chain monitoring via `auditd` output to JSONL.

7. Unified `ash` CLI Tool

  • ash vibe start: Enters a vibe-coding session with Btrfs snapshots enabled.
  • ash context [query]: Semantic search across local code, NotebookLM, and web cache.
  • ash research [query]: Background web research scraping to Qdrant.
  • ash explain --diff: Uses AI to explain massive git diffs dynamically.
  • ash branch [name]: OS-level workspace branching (Git for sessions).

8. Multi-Node Cluster & Scaffolding

  • ash-cluster: Docker Compose + HashiCorp Nomad orchestration (`ash-cluster up --nodes N`).
  • ash-new: Project templates (Python FastAPI, Rust Cargo, TypeScript Next.js, Jupyter) pre-configured with DevContainers, Makefiles, and GitHub Actions.
  • ash-conf: Manage dotfiles via GNU Stow (apply/diff/rollback/export).
