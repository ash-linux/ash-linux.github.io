What You Get

Semantic File Search

Press Super+Space, type what you mean — "budget spreadsheet", "backup script", "my config". Finds files by meaning, not just filename.

Qdrant Vector Database

Persistent vector memory that survives reboots. Every file is embedded and searchable within seconds of being saved.

Ollama + nomic-embed-text

Runs locally — no cloud, no API keys. Converts your files into 768-dimension meaning vectors for instant semantic retrieval.

Desktop Integration

Hyprland + Waybar + Kitty + Wofi + wlogout — full Catppuccin-themed desktop. Auto-login, auto-start, auto-index.

Rollback & Safety

Btrfs snapshot before every change. Idempotent installer — re-run anytime to repair or update. No destructive changes.

Single Command Setup

Interactive TUI (like archinstall) or silent mode. Detects your system, installs everything, and shows a live dashboard.

How It Works

1

Run the installer

One curl | sudo bash. Interactive TUI guides you through. Btrfs snapshot taken before any change.

2

Qdrant + Ollama start

Vector database and embedding engine boot as systemd services. The nomic-embed-text model is pulled and pinned in memory.

3

Your files are indexed

LSFS daemon walks your home directory, embeds every text file, and stores the vectors in Qdrant. New files indexed in real-time.

4

Search by meaning

Press Super+Space, type "my backup scripts" or "files from last 2h". Results appear instantly — ranked by semantic similarity.

FAQ

Only for the initial setup (package download, model pull). After that, everything runs 100% offline. No telemetry, no phone-home.

Base system ~5 GB. AI model ~300 MB. Qdrant database grows based on files indexed — typically under 500 MB.

The core components (Ollama + Qdrant + LSFS) work on any Linux distro. The installer targets Arch — porting to Ubuntu/Fedora would replace pacman calls.
